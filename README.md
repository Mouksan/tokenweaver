# Tokenweaver

Счётчик контекста для SillyTavern: показывает размер последнего основного запроса к модели отдельно от боковых запросов расширений (комментарии, промты для картинок и т.п.).

## Основа

Сделано на основе [ST Context Counter](https://github.com/niemandswasser/ST-Context-Counter) авторов niemandswasser и KiskaSora (Apache License 2.0). Табло, перетаскивание, оформление и счётчик скрытых сообщений взяты оттуда. Перехват запросов переписан.
